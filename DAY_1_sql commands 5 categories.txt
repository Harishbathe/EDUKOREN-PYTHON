sql commands 5 categories

1. DDL --> data definition language  --> auto commit 
	create , alter, rename, truncate, drop

2. DML -> data manu/modi language  -> no
	insert, update, delete, merge(upsert)

3. DQL -> data query language  --> no
	select, 

4. DCL -> data control language  --> yes
	grant, revoke, 

5. TCL -> Transactional control language --> no
	commit, rollback, savepoint


oracle server --> database --> tablespaces --> users(schemas)--> Tables, view, indexes, store procedures
